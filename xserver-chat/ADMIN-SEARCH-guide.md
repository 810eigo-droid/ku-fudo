管理者の検索ページ（別ページ版）

既存ページを変更せず、admin-search.php と admin-search.css の2ファイルを追加する版です。
現在の管理者ログインと会員データを利用します。新しい画面で登録・変更・削除・メール配信は行いません。

設置：
ZIPを展開し、ku-fudo-chat内の2ファイルだけを
 taf-design.com/public_html/ku-fudo-chat/
へ追加してください。既存のindex.php、bootstrap.php、config.php、データベースなどは上書きしません。
同名ファイルが既に存在する場合は、上書き前にそのファイルを控えてください。

使い方：
1. 従来の会員チャットで管理者としてログインします。
2. https://taf-design.com/ku-fudo-chat/admin-search.php を開きます。
3. 左側で項目を選び、名前やキーワード、日付などで検索します。
4. 会員名をクリックすると、その人の登録情報、地区、6レッスンのチェック、祈りの直近提出月、会費記録を確認できます。
ブラウザーの戻る、検索結果へ戻る、ページ送りに対応しています。

対象：会員、Zoom・お知らせ、議事録、REDO MAIL、祈りの提出状況、新しいメール配信画面の履歴。
メール配信の検索対象は mail-center.php で作った案内です。REDO MAILの送信結果は従来のREDO管理画面で確認してください。
地区検索はメール配信機能で設定した地区を使用します。未設置の機能は「データはまだありません」と表示します。
会員検索は登録済み会員が対象です。承認前の申し込みは従来の管理画面で確認してください。
祈りの提出状況は選択月の参加期間に該当する、利用中の参加者が対象です。
本人のメモ・パスワード・ログイン用トークンは取得・表示しません。
一般会員・理事・理事候補の権限だけではこの新ページは開けません。管理者専用です。
編集や配信は「従来の管理画面へ」または各詳細リンクから行ってください。

取り外す場合：追加したadmin-search.phpとadmin-search.cssだけを取り除けば、従来どおり利用できます。既存ページやOLD版は変更していません。
GitHub PagesではPHPが動かないため、この画面はエックスサーバーで確認してください。

検証：PHP 8.3の一時環境で権限・検索6種・絞り込み・ページ送り・メモ非表示・未設置機能・不正入力を確認しました。実サーバーへの設置は未実施です。
