メール配信機能 統合更新版（2026年9月12日）

【含まれるもの】
現在のトップ・6本のカリキュラム、マイページ、REDO MAIL、祈りの蓄積、議事録・地区担当者、今回のメール配信機能を含みます。祈り2更新が未設置でも、このZIPだけで更新できます。
会員の個人情報・設定・データベースは含みません。トップデザイン・OLD・OLD2を変更しません。

【設置】
1. 利用者が操作していない時間に、現在のku-fudo-chat、ku-fudo-demo、公開領域外のku-fudo-privateを控えてください。個人情報の控えをpublic_html内に置かないでください。
2. ZIPをPCで展開します。
3. ku-fudo-chatの中身27ファイルを taf-design.com/public_html/ku-fudo-chat/ に上書き。
4. ku-fudo-demoの中身8ファイルを taf-design.com/public_html/ku-fudo-demo/ に上書き。
既存フォルダは削除しません。フォルダを二重に入れません。config.php・データベースは上書きしません。SQLの手動実行は不要です。
古いZIPを後から重ねないでください。サーバーだけで独自編集したファイルは事前に差分をご確認ください。
5. 管理者で https://taf-design.com/ku-fudo-chat/ にログインし、
   https://taf-design.com/ku-fudo-chat/mail-center.php を開きます。
必要な表は自動追加します。旧REDO版からの更新時は祈り用の形式9への更新も実施します。

【Zoom予定・月例会・お知らせ】
「メールでお知らせ」から種類、対象、件名、本文、日時、参加リンクを入力します。
「下書き保存して確認する」→内容・送信先の名前と人数を確認→「公開してメール送信」。
本文・開催日時・参加リンクを一人ずつメールで届けます。
全体・地区の案内は全体チャット、理事・理事候補向けの案内は理事＆理事候補チャットに公開します。
地区指定はメールの送信先です。地区の案内もサイトでは全体に見えます。
従来のチャット投稿やお知らせ投稿だけではメールを送りません。メールも必要な場合は新しい画面を使います。
送信開始後は画面を開いたままお待ちください。10件ずつ順に送信します。
閉じても配信履歴から残りを送れます。JavaScriptが使えない場合は10件ずつボタンで送ります。

【担当者と地区】
管理者：全体・理事向け・地区・祈りの配信ができます。
理事・理事候補：議事録と理事向け月例会・お知らせを配信できます。
指定された地区担当者：自分の地区の案内を作成・配信できます。
管理者は「会員の地区設定」で名前を検索し、担当者の地区名と同じ表記で登録してください。複数地区も登録できます。
対象地区の会員が未設定だと0人になり、送信できません。

【議事録】
議事録を下書き保存し、仕上がりを確認します。
「公開してメールでも知らせる」→「議事録メールの確認へ」→宛先と内容を確認→「公開してメール送信」。
本文と資料リンクを理事・理事候補・管理者へ送ります。既に公開した議事録にもメール案内の入口があります。
同じ議事録の同じ版は二重に配信しません。本文を変更した場合は、議事録側で保存・確認して新しい版のメールを準備してください。
送信前に元の議事録が変更された場合は古い内容を送らず停止します。

【祈りの蓄積】
先に「集計・参加者管理」で番号・参加期間を登録します。
「メールでお知らせ」で「祈りの蓄積・入力案内」を選び、対象月・挨拶文を入力します。
対象月の参加者だけがメールの宛先になります。同じ案内を祈りページにも掲載します。
入力URLはメールに自動で載せます。毎月、担当者が確認して送る方式です。日付による自動予約配信ではありません。
個人の実践数・感想・マイページのメモは一斉送信しません。提出後の本人への控えメールは従来通りです。

【REDO MAIL】
従来のREDO MAIL管理画面で発行・メール配信を行います。
有効なやりなおし会員のうち受信希望者へタイトルと本文・PDFの閲覧リンクを送ります。PDFの添付や本文全体のメール配信ではありません。

【受信設定・配信結果】
会員はアカウントの「お知らせメールの受信設定」で受信停止できます。REDO MAILは別設定です。
送信処理完了・待機・失敗・結果未確定・対象外を表示します。
失敗分だけ再送できます。送信済みは再送しません。結果未確定は実際に届いている可能性があるため自動で再送しません。
配信中に退会・資格喪失・メール変更・受信停止となった人は残りの配信対象から外します。
サーバーの送信受付と、受信箱への到着は異なります。

【送信元】
初期値 info@taf-design.com。必要な場合のみ非公開config.php配列に以下を追加します。
'notice_mail_from' => 'info@taf-design.com',
'notice_mail_enabled' => true,
'chat_login_url' => 'https://taf-design.com/ku-fudo-chat/',
初回はご自身だけを登録したテスト地区宛てに、実メールの受信を確認してから本番配信してください。

【確認したこと・未確認のこと】
PHP 8.3一時環境で会員・祈り・REDOの既存456 APIチェックと権限16ケース、新しい配信の宛先・承認・重複・失敗・複数バッチ・権限剥奪・受信停止・個人情報の分離を確認しました。テストメールはローカル模擬送信のみです。
実サーバーへの設置・実メールの受信・ウイルス対策ソフトでの安全判定は未確認です。再度ウイルス検出された場合は保護を解除せず設置を止めてください。
