## 設置
1. このZIPをPCで展開します。
2. サーバーの taf-design.com/public_html/ku-fudo-chat 内の index.php と chat.js をPCへダウンロードしてバックアップしてください。
3. ZIP内の ku-fudo-chat フォルダにある5ファイルを、同じサーバーフォルダへアップロードします。
   index.php / chat.js / operations.php / operations.css / operations.js
4. https://taf-design.com/ku-fudo-chat/ にログインし直します。
既存のフォルダ全体は削除しません。bootstrap.php、chat.sqlite、config.phpは上書きしません。PHP8.2以上の既存チャットが必要です。

## 議事録の作成
理事・理事候補・管理者が、チャット上部の「議事録」を開きます。同じアカウントを使い、別の管理者登録は不要です。
1. 「議事録を新しく作る」を押します。
2. 会議名、開催日、開始・終了時刻、参加者、司会・書記・Zoomホスト、式次第を入力します。会議名・開催日以外は省略できます。
3. 議題ごとに「話し合った内容」「決定事項」「担当者」「対応期限」を入力します。「＋議題を追加」で30件まで追加でき、不要な議題は削除できます。
4. 次回予定・連絡事項・資料や動画のリンクを必要に応じて入力します。
5. 「下書き保存して仕上がりを確認」を押します。
6. 確認画面で「この内容で公開する」を押します。
前回を使う場合は、保存済みの議事録で「この議事録をコピーして新規作成」を押します。会議名・開催日を入れ直し、内容を今回のものに直します。元の記録は変わりません。

理事・理事候補・管理者は、全員が議事録と下書きを閲覧し、共同で編集できます。担当交代時も引き継げます。一般会員・無料会員・地区のお知らせ担当者（理事等の権限がない方）は閲覧できません。
公開済みの議事録を修正して保存すると下書きに戻ります。内容確認後に再公開してください。同時編集で他の担当者が先に更新した場合は、上書きを拒否して入力内容を画面に残します。
会議の実データはZIP・GitHubには含みません。最初は空の状態です。前に提示いただいた実際の議事録は参考資料としてのみ扱っています。
外部Google文書や動画は元のサービスの共有設定が適用されます。このサイトの権限は外部リンク先を制限しません。限定の内容は本文欄へ入力してください。

## 地区代表者の設定と投稿
管理者：アカウント内の管理欄→「地区のお知らせ担当者を設定」→名前で検索→地区名を入力→「お知らせの投稿を許可する」にチェック→保存。
担当者が変わる場合は、旧担当者のチェックを外して保存し、新担当者を指定します。次の投稿操作から新しい権限が適用されます。新担当者に管理者権限を付ける必要はありません。
担当者：ログインし直す→「お知らせ投稿」→タイトル・本文を入力→Zoom開催日時と参加リンクを必要に応じて入力→「全体に公開する」。
指定された地区名が自動で付きます。地区代表者は他地区名へ書き換えられません。管理者は地区名を指定できます。
無料・有料・お試しの区別は本文に記載します。未来の開催日時がある投稿は既存のZoom予定にも表示されます。
指定した担当者のお知らせは、無料会員区分でも承認待ちを経ず全体に公開されます。通常のチャット投稿の承認ルールは変わりません。投稿後は既存チャットの「取り下げる」で自分の投稿を取り下げられます。

## 今回の範囲
サイト内での作成・保存・公開です。メールの一斉送信、PDF出力、ファイル添付、個別の校閲承認、過去版への復元は今回含みません。議事録の公開・保存操作は既存の監査ログに記録しますが、本文の変更履歴を復元する機能ではありません。
既存のデータベースへ議事録と地区担当者のテーブルを追加します。従来データとバージョン番号は維持します。REDOまでのDB8、祈りを含むDB9の双方で隔離テストを実施しました。
