# REDO MAIL・やりなおし会員の使い方

## 今回の方式

- やりなおし会員は、既存の無料・通常会員とは別の有料会員制度です。
- 全員共通で毎年2月1日から翌年1月31日まで（仮設定）。例：2026年度は2026年2月1日〜2027年1月31日。
- 途中入会も終了日は同じです。入会日・入金日・実際の振込額を管理者が記録します。月割り金額の自動計算はありません。
- 既存会員にはREDO資格を自動付与しません。REDO専用アカウントには既存チャット・会員教材の権限を自動付与しません。両方の資格を持つ方は同じアカウントで利用できます。
- 銀行振込の手動確認に対応します。Stripe・自動引落し・自動入金確認は含みません。

## アップロード

1. 更新前に、現行コードと非公開の `ku-fudo-private` のバックアップを保管してください。会員・投稿・入金記録・配信状況は `chat.sqlite`、PDFは `redo-pdfs` に入ります。公開フォルダへバックアップを置かないでください。
2. `ku-fudo-redo-update.zip` を解凍します。
3. `ku-fudo-chat` 内の13ファイルを `taf-design.com/public_html/ku-fudo-chat/` に上書き・追加します。フォルダを二重に作らないでください。
4. `ku-fudo-demo` 内の2ファイル（index.html / style.css）を `taf-design.com/public_html/ku-fudo-demo/` に上書きします。
5. `ku-fudo-private` の config.php や chat.sqlite を空ファイルで上書きしないでください。新しいファイルには実際の会員データを含めていません。
6. 管理者として `https://taf-design.com/ku-fudo-chat/redo.php?manage=1` を開きます。保存データの移行は初回アクセスで自動実行され、既存会員・投稿を引き継ぎます。

この更新ZIPの他、通常のチャット更新ZIPも今回から13ファイルです。全体設置ZIPにも全変更を含めています。

## 会員登録と銀行振込

管理画面の「やりなおし会員の管理」で対象年度を選びます。

- 既存会員：会員一覧から「この年度に登録」を選ぶ。
- 未登録：先に「未登録の方を追加」で名前とメールを登録する。仮パスワードの案内を本人に個別に伝える。初回はご本人が8文字以上のパスワードへ変更する。
- 入金を確認したら入会・利用開始日、入金日、入金額、資格「有効」を保存する。
- REDOだけの方は「既存のチャット・会員教材も利用できますか」を「利用しない」のままにする。
- 両方の会員なら「利用する」を選ぶ。変更時はログインし直しが必要。
- 継続会員：翌年度を選び、新しい入金を登録する。過去年度の記録は残り、翌年2月1日から新年度の資格が有効になる。
- 入会前・期限切れ・停止中は本文・PDFを読めず、配信対象にもならない。
- 管理画面には対象年度の残り30日以内・終了を表示する。更新案内の自動メールはない。
- 会員削除は既存の会員管理画面から行う。削除するとその方のREDO入金記録・配信履歴も削除するため、必要な記録は削除前に保管する。

※開始月の2月は現在の仮設定です。正式な開始月が変わる場合は既存年度データとの整合を確認してから変更してください。

## 発行する

1. 「新しい号を作成」に号数、シリーズ、配信日、タイトル、本文を入力する。
2. 必要ならPDF（10MB以内）を選び「下書きを保存して確認」を押す。
3. 本文とPDFを確認する。本文は文字のまま表示し、HTMLは実行しない。
4. 「公開してメールで知らせる」を押し、対象人数を確認して確定する。
5. 送信中は管理画面を開いたままにする。5件ずつ順に送信し、途中停止・再開できる。

過去号の登録など通知が不要なら「公開のみ（メールなし）」を選びます。この版では公開のみで発行した号を後から一斉送信する機能はありません。

配信日は表示用です。未来の日付を入力しても予約配信にはなりません。確定した時点で公開されます。

公開後は誤配信や内容の取り違えを防ぐため、本文・PDFの変更を止めています。修正が必要な場合は「公開を停止」し、訂正版を新しい号として作成してください。送信済みのメールは取り消せません。

## 配信と閲覧

- 既定の送信元は `info@taf-design.com`。本人1名ごとに個別送信し、他の受信者のアドレスをメール本文や宛先に入れません。
- メールに「今号を読む」ボタンを載せます。本文やPDFはメールへ添付せず、会員資格を確認するサイト内で提供します。
- メールを開いて未ログインならログインへ案内し、ログイン後にその号に戻ります。
- 会員自身がREDO画面で配信停止・再開できます。停止しても有効期間中はサイトで読めます。
- PDFは非公開フォルダに保存し、認証済みの閲覧URL経由だけで返します。PDFの公開URLは作りません。端末によっては「PDFを開く・保存する」でダウンロードされます。
- 会員が一度保存したPDFのコピーを回収・複製防止する機能はありません。
- 有効な資格を持つ方は、公開済みの過去号も読めます。年度別の過去号制限はありません。

## 配信結果

「送信処理完了」はサーバーのメール送信処理が受け付けた状態で、受信箱への到着確認ではありません。「送信失敗」は再送待ちに戻して再開できます。実行中に接続や処理が途切れて「結果未確認」となったメールは、自動再送しません。受信状況やサーバーのログを確認してから対応してください。

送信開始時と各送信時に会員資格・配信希望・アカウントの有効状態を確認します。送信中に資格を停止しても、既にメールサーバーへ渡ったメールは取り消せません。

大量配信時はサーバーの送信制限に合わせた調整が必要です。今回の設置後は、まず管理者用テスト会員1名だけを有効にして、下書き・PDF・メール到着を確認してください。実際の銀行データや会員宛て送信は開発テストで扱っていません。

## 設定（通常は変更不要）

既存の非公開config.phpを引き継ぎます。任意の設定：

```php
'redo_mail_from' => 'info@taf-design.com',
'redo_mail_enabled' => true,
'chat_login_url' => 'https://taf-design.com/ku-fudo-chat/',
```

PDFをアップロードするにはPHPのfile_uploadsが有効で、upload_max_filesizeとpost_max_sizeに余裕が必要です。アプリ側の上限は10MBです。サーバー側の上限が小さい場合は、その上限が優先されます。

## 確認した内容

PHP 8.3のテスト環境で既存チャットの権限・投稿、会員資格の分離、年度更新、PDFアップロード・限定閲覧、公開前非表示、資格停止、配信停止、二重公開の拒否、送信失敗と再送を確認。メールはテスト用の代替送信処理で検証し、実メールは送信していません。サーバー設置後の到達性・実機確認は別途行ってください。
