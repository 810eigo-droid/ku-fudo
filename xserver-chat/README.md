# 献文舎 会員チャット — エックスサーバー設置版

**画面だけのサンプルではなく、PHP＋SQLiteで投稿をサーバーに保存する実装です。ただし、エックスサーバーへの設置・実機確認はまだです。GitHub Pages上では動きません。**

## できること

| 機能 | 内容 |
|---|---|
| 全体チャット | 一般会員・理事候補・理事・管理者が閲覧・投稿・返信 |
| 理事＆理事候補チャット | 理事候補・理事・管理者のみ。APIでも権限を検証 |
| 献文舎のお知らせ | 管理者がタイトル・本文・対象地区・開催日時・Zoom参加リンクを投稿 |
| 開催予定 | 現在の部屋に投稿された、今後のZoomを日時順で最大20件表示（日本時間） |
| 会員申し込み | 共通URLから氏名・メールアドレス・8文字以上のパスワードを入力。管理者承認後に一般会員として利用 |
| 会員管理 | 管理者が会員を追加、専用リンク・案内文を発行、役割を指定、利用停止、仮パスワードを再発行 |
| かんたんログイン | 本人専用リンク →「チャットに入る」の2操作。文字入力不要。管理者を除く会員に利用可 |
| パスワード | 従来のメールアドレス・パスワードも利用可。仮パスワード方式は初回変更必須 |
| 投稿取り下げ | 自分の投稿、または管理者が投稿を非表示化。物理削除はしない |
| 更新 | 画面を開いている間、約20秒間隔で更新。過去ログ閲覧中は手動更新 |
| スマホ | 1段のコンパクトな固定メニューと、右下の上に戻る矢印 |

通常の投稿は全員が行えます。「献文舎からのお知らせ」の投稿は管理者だけです。
理事・理事候補は限定チャットを使えますが、会員管理はできません。
一般会員には限定チャットの部屋名や本文・開催予定を配信しません。

## 今回は含めないもの

Stripe決済、承認通知以外の自動メール、メールによる本人確認・パスワード再発行、画像や動画のアップロード、スマホプッシュ通知、既読、個人間DM、カリキュラムとのログイン統合。
Zoom会議自体を作成する機能ではなく、既に用意した参加リンクを案内する機能です。
会員一覧は直近500件まで。大人数・高頻度利用には負荷試験やデータベースの見直しが必要です。

## 1. 設置前に

- 対象：taf-design.com の専用フォルダ。既存WordPressは変更しません。
- 必要：HTTPS、PHP 8.2以上のサポート中バージョン、PDO SQLite、mbstring、非公開ディレクトリへの書き込み権限。
- PHPバージョンを変更する場合、同ドメインのWordPressへの影響を先に確認してください。
- エックスサーバーのWAFを一括で無効にしないでください。操作が拒否された場合はログと対象ルールを確認します。
- 現在のソースは公開GitHubにあります。実際の会員情報・パスワード・Zoom参加リンクは一切GitHubへ置かないでください。

## 2. ファイル配置（重要）

GitHubで Code → Download ZIP を選び、PCで展開します。
エックスサーバーのファイルマネージャーで対象ドメインのフォルダを開きます。

| 保存先 | 入れるもの |
|---|---|
| `taf-design.com/public_html/ku-fudo-chat/` | このフォルダ内の `ku-fudo-chat` にある全ファイル（.htaccessも含む） |
| `taf-design.com/ku-fudo-private/config.php` | `private-template/config.php.example` を編集してconfig.phpに改名したもの |

**ku-fudo-privateはpublic_htmlの中ではなく、public_htmlと同じ階層です。**
会話・会員情報・セッションはここへ保存します。フォルダ名・配置は変更しないでください。
同名フォルダがある場合は上書きせず確認してください。
必要に応じて非公開フォルダの権限を700、config.phpを600にします。777にしないでください。
既存のpublic_html直下の .htaccess や index.php は変更しません。
WordPressの同名ページがないことも確認してください。

## 3. 初期設定キー

config.php.example の空欄 `setup_key` に、パスワードマネージャーなどで生成した **32文字以上のランダムな英数字** を入れます。例文や使い回しの値は使わないでください。
このファイルは非公開フォルダにのみ保存し、チャットやGitHubには送らないでください。

## 4. 管理者の登録

1. `https://taf-design.com/ku-fudo-chat/` を開きます（設置後のみ有効）。
2. 初期設定キー、管理者の表示名、メールアドレス、パスワードを入力します。
3. 初期設定が完了したら、非公開config.phpの `setup_key` を空文字に戻します。
4. 必要な会員を「アカウント → 会員管理」で追加します。
5. 案内方法は「専用リンク」を選び、表示された「案内文をコピー」を押して、LINEやメールで本人に個別に送ります。自動送信はされません。
6. 会員はリンクを開いて「チャットに入る」を押すだけです。管理者を追加した場合や仮パスワード方式を選んだ場合は、仮パスワードを個別に伝え、初回ログイン時に本人がパスワードを変更します。

管理者の権限は運営担当者にのみ付与してください。一般会員に自由登録させない方式です。
新しく設定するパスワードは8文字以上、最大72バイトです。英数字なら8〜72文字です。日本語も文字数で判定し、8文字未満は受け付けません。既存パスワードでのログインには新しい最低文字数を遡って適用しません。
通常のパスワードログインは最大12時間です。専用リンクで「この端末で30日間ログインを保つ」にチェックした場合は、同じブラウザで最大30日間ログインを保持します。チェックを外すと最大12時間・ブラウザセッション限定です。ログアウト、会員設定やパスワードの変更、Cookie削除などで早く失効する場合があります。サーバー側でも期限と会員の有効状態を確認します。
管理者が全員ログインできなくなった場合は、DBを削除して再設定せず、サーバー管理者に復旧を依頼してください。

## 5. 必ずテスト会員で確認すること

本物の会員を招待する前に、別ブラウザまたは別端末で以下を確認してください。

- 管理者・一般会員・理事候補・理事のテストアカウントを作成し、初回パスワード変更。
- 管理者が全体へ投稿 → 別端末の一般会員で読み、返信 → 管理者で反映を確認。
- 理事候補・理事が限定チャットで相互に投稿・返信できる。
- 一般会員で `api.php?action=feed&room=board` を直接開く → 403で本文・予定が返らない。
- 一般会員によるboardへのPOST、boardの投稿IDをallから返信・取り下げる操作が拒否される。
- 一般会員の会員一覧取得・会員作成・権限変更・お知らせ投稿が拒否される。
- 未ログインでfeed/usersへアクセス → 401。CSRFトークンなしのPOST → 403。
- 限定チャットにZoom予定を登録しても、全体チャットの予定に混ざらない。
- 利用停止・一般会員への降格後、対象会員の既存ログインが無効になる。
- 再読み込み・別端末からでも投稿が残る。50件を超えたら「以前の投稿」を読める。
- 投稿に `<script>` などを含めても文字として表示される。取り下げた本文や返信引用は非表示になる。
- スマホで固定メニューと返信・送信が使え、文字が画面外にはみ出さない。
- HTTPS以外では操作できない。公開領域にDB・config・セッションが置かれていない。
- 通信エラー時は投稿内容が残る。送信結果不明のときは更新して重複投稿がないか確認する。

## バックアップ・運用

サーバーのバックアップ対象にpublic_htmlの外側のku-fudo-privateが含まれるか確認してください。
SQLiteは書き込み中のファイル単純コピーを避け、SQLiteのbackup機能または運営停止中のコピーで取得します。
バックアップも公開フォルダや公開GitHubへ置かないでください。復元テストを行ってください。
取り下げた投稿の原文と操作監査は非公開DBに残ります。保存期間・完全削除の方針は運営側で決めてください。
退会時は管理画面で利用停止。既に会員が見た・保存した内容を回収することはできません。
送信が多いときやログイン試行が続いたときは、一時的に操作制限がかかります。
自動更新はスマホへの通知ではありません。閉じた画面への通知は未実装です。

ただしエックスサーバー実機、Apacheの設定、ブラウザ操作、負荷・同時接続の試験は未実施です。設置後、上記受け入れ確認が必要です。

GitHub PagesへPHPを置いても実行されません。動作確認はエックスサーバー上で行ってください。

## 入力不要の本人専用リンク（最新版）

### 管理者の操作

- 登録済み会員：「アカウント → 会員管理」で対象者の「専用リンクを発行」を押します。
- 新規会員：メールアドレス・表示名・権限を登録し、案内方法「専用リンク」のまま追加します。
- 「案内文をコピー」を押し、本人へのLINE・メール等へ貼り付けて送ります。全体チャット・グループ・公開ページへ貼らないでください。専用リンクを持つ人は対象者として入れるため、受取人を確認して個別に送ってください。
- 一般会員・理事候補・理事に発行できます。管理者は従来のメールアドレス・パスワード方式です。
- 本番のリンクを管理者自身のブラウザで試しに使用しないでください。動作確認には別途テスト会員を使います。

### 会員の操作

1. 個別に届いた本人専用リンクを開く。
2. 大きな「チャットに入る」を押す。メールアドレス・仮パスワード・新しいパスワードの入力は不要です。
3. 入室後の通常ページ `https://taf-design.com/ku-fudo-chat/` をブックマークする。次回は同じ端末・ブラウザで開きます。

個人の端末では「この端末で30日間ログインを保つ」を利用できます。共有端末ではチェックを外し、利用後にログアウトしてください。LINE内ブラウザとSafari/Chromeはログイン状態が別になる場合があります。最初から普段使うブラウザで開き、次回も同じブラウザを使ってください。
ログアウトした場合・30日経過・Cookie削除・別端末では、新しい専用リンクを管理者に依頼するか、設定済みのパスワードでログインします。既にログインしている端末で専用リンクを開くと、現在のアカウントを確認してそのままチャットへ進めます。

### 有効期限とアクセス制限

- 1つのリンクは発行から72時間（3日間）・1回限りです。再発行すると以前の未使用リンクは無効です。
- ページを開くだけではリンクを消費しません。確認ボタンを押した時だけ、CSRF保護付きPOSTでログインします。
- 仮パスワード変更待ちの会員が専用リンクで入る場合、仮パスワードを無効化して変更待ちを解除します。以後は専用リンク方式を使います。
- 登録済みの本パスワードを持つ会員は、リンク方式とパスワード方式の両方を使えます。
- 利用停止・権限変更・パスワード再発行・メールアドレス変更後は、以前のリンクとセッションが使えません。端末紛失時は管理者が利用停止にしてください。
- 一般会員が理事の部屋を見ることはできません。リンクに役割を埋め込まず、毎回サーバーの会員情報を確認します。
- リンクは32バイトの暗号学的乱数を用い、DBにはSHA-256ハッシュだけを保存します。ブラウザ側ではURLフラグメントから読み取り、履歴のURLから除去します。CookieにはSecure・HttpOnly・SameSite=Strictを設定します。
- トークンの単回利用・期限・安全な保存とセッションの取り扱いは、[OWASPのトークン管理指針](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)・[セッション管理指針](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)を参照しています。これはパスワード再設定ではなく、管理者が個別発行するログイン用の招待方式です。

### 更新と確認

設置済みフォルダの5ファイルを上書きします。会員・投稿を保存した `ku-fudo-private` は上書き・削除しません。既存DBは初回アクセス時にversion 1から2へ更新し、専用リンク用テーブルだけを追加します。会員番号・権限・投稿は保持します。古いbootstrap.phpへ戻す場合はversion 2に非対応のため、そのままでは動作しません。

## 2026-09-09：登録画面とスマホの「戻る」

共通の入口は `https://taf-design.com/ku-fudo-chat/`。初回申し込みを直接開く場合は `https://taf-design.com/ku-fudo-chat/?register=1` です。使い捨てリンクではありません。

1. 本人が「初めての方はこちら → 会員登録」から、お名前・メールアドレス・8文字以上のパスワードを入力し「登録を申し込む」を押します。
2. 管理者が通常のブラウザでログインし「アカウント → 会員管理 → 登録の申し込み」を開きます。「申し込みを更新」で再取得できます。
3. 本人の名前・連絡先を確認して「承認する」を押します。info@taf-design.com から本人へ承認メールを自動送信します。メール所有の確認機能はないため、承認前に本人の名前・連絡先を照合してください。
4. 本人は共通の入口から、申し込んだメールアドレスとパスワードでログインします。仮パスワードへの変更手順はありません。自分の端末では30日間のログイン保持が選べます。シークレットウィンドウをすべて閉じると保持されません。

申し込み時点ではチャット・Zoom・会員一覧を閲覧できません。承認では必ず一般会員になります。理事・理事候補への変更は管理者が会員設定で行います。二重申し込みで登録済みのパスワードが変わることはありません。未処理の申し込みは最大500件で、30日を超えた分は次の申し込み処理時に削除されます。

データ形式は既存データを維持してバージョン5へ自動更新します。会員・投稿を保存する非公開フォルダを上書きしないでください。

教材詳細はブラウザの戻るで一覧へ、進むで詳細へ戻れます。閉じる・学習完了も一覧へ戻ります。チャットの部屋切り替えとZoomリンクは通常のページ移動を使い、ブラウザの戻るに対応します。再表示時には閲覧権限を再確認し、過去投稿は最大20ページまで再取得して位置を復元します。Zoomアプリへ切り替わった場合はブラウザへ戻ってください。投稿・取り下げ・承認など確定した操作は、戻るでは取り消されません。

更新用ZIPの5ファイル（api.php、bootstrap.php、index.php、chat.js、chat.css）を `taf-design.com/public_html/ku-fudo-chat/` に上書きしてください。GitHubへの反映だけではエックスサーバーは更新されません。

## 承認メールの自動送信

「登録の申し込み」から承認したとき、info@taf-design.com を差出人・返信先として、本人へメールを自動送信します。「チャットを開く」ボタンとログイン先を掲載し、パスワードや専用ログインキーは送信しません。HTML版とテキスト版を同梱します。

今回の設置先ではPHPのmail()とサーバー内のメール配送機能を利用します。メールのパスワードをファイルやGitHubへ保存する必要はありません。ただし、サーバー側のメール送信制限・送信ドメイン認証・受信側の迷惑メール判定により届かない場合があります。設置後、ご自身のテスト用会員を新規に申し込み・承認し、実際の受信とボタンの動作を確認してください。

承認と送信予定の保存を同じトランザクションで行い、承認を保存した後にメールを送信します。送信が失敗しても承認は完了しています。「アカウント → 会員管理 → 承認メールの送信履歴」で状態を確認し、未送信・送信失敗を再送できます。「送信処理完了」はサーバーが送信を受け付けた状態で、受信箱への到着確認ではありません。送信結果不明のまま10分を超えたものは、重複する可能性を確認して手動再送できます。

以前に承認済みの会員には、この更新だけでメールを送信しません。管理者による直接追加・本人専用リンクの発行も、この自動メールの対象外です。

移設時などは、非公開config.phpの配列に次の任意項目を設定できます（今回の既定値と同じなら追記不要）。

```php
'approval_mail_enabled' => true,
'approval_mail_from' => 'info@taf-design.com',
'chat_login_url' => 'https://taf-design.com/ku-fudo-chat/',
```

移設先で管理する送信元メールアドレスとログインURLに変更してください。自動送信を停止する場合はapproval_mail_enabledをfalseにします。送信は管理者の承認・再送操作に限定し、公開の申し込みだけではメールを送信しません。

検証ではメール配送部分をテスト用の記録処理に置き換え、実在するメールアドレスへは送信していません。承認時の宛先・本文、失敗時の会員維持、再送、送信済みの重複防止、一般会員の送信操作拒否を確認しています。実際のサーバーからの到着確認は設置後に行ってください。

## 会員の削除

「アカウント → 会員管理」で対象会員の「会員を削除」を押し、名前・メールアドレスと確認文を確認します。自分自身の管理者アカウントは削除できません。削除すると会員一覧から消え、セッション・専用リンク・元のパスワードが使えなくなります。会員の名前・メールアドレスを匿名化し、承認メール履歴も削除します。一般会員による削除や、削除済み会員の再有効化はAPIで拒否します。

過去の投稿・返信は会話を保つため「退会済みの会員」として残ります。投稿本文に書かれた名前・連絡先は自動では消えないため、必要なら管理者が該当投稿を取り下げてください。操作は元に戻せません。本人が改めて利用する場合は新規申し込み・承認が必要で、以前の投稿とは別の会員アカウントになります。
