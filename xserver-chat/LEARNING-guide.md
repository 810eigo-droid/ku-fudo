# 学びのマイページ

登録済みの会員がログインし、6本の動画について視聴済みと自分のメモ（各5,000文字まで）を保存できます。記録は会員IDごとに非公開フォルダの既存SQLite内に保存し、ブラウザーを閉じても残ります。管理者を含め他人のメモを表示する画面はありません。サーバー管理者はデータベースの管理権限を持つため、技術的に閲覧不能という意味ではありません。

## 設置
1. ZIPをPCで展開してください。
2. ku-fudo-chat 内の learning.php と learning.css の2ファイルを taf-design.com/public_html/ku-fudo-chat に追加します。同名がある場合は先に旧ファイルを別名で保存してください。
3. ku-fudo-demo/index.html は現在の index.html をバックアップしてから、taf-design.com/public_html/ku-fudo-demo/index.html に上書きします。直前の TOP-latest 版CSS・JS・画像が設置済みであることが前提です。
4. https://taf-design.com/ku-fudo-chat/learning.php を開きます。ログイン済みならそのまま利用できます。

未ログインの場合：ログイン画面を開く→ログイン（必要なら初回パスワード変更）→ブラウザーの戻るでこの画面へ戻る→「マイページを開く」を押します。トップにも入口を追加しています。
視聴済みチェックとメモを入力し「保存する」を押してください。メモを空にして保存すれば消せます。自動保存ではないため、動画を開く前にも保存してください。

チャットのbootstrap.phpや既存DBを上書きしません。REDO MAILまでの版（DB8）と祈り機能を含む版（DB9）の両方で確認しています。既存DB内に learning_notes テーブルを追加し、全体のバージョン番号を変更しません。
トップ画面の進捗は従来の一時表示です。アカウントに保存した正式な記録はマイページで確認します。
この更新のためのメール送信・会員情報の外部送信はありません。サーバー未設置です。

## 確認
PHP8.3の隔離テスト環境で、未ログイン閲覧制限、会員間分離、再ログイン後の保持、CSRF拒否、同時編集の競合、HTML文字の無害化、未知教材・文字数の検証、チェック解除・メモ消去を確認しました。実際のXserverとスマホブラウザーでの最終確認は設置後に実施してください。
