パスワード再設定機能（2026年9月12日）

会員自身が登録メールアドレスを入力し、有効期限30分・1回限りのメールリンクから新しいパスワードを設定できます。現在のパスワードをメールで送る方式ではありません。

設置：
現在の ku-fudo-chat/index.php を手元に控えます。
ZIP内の ku-fudo-chat/password-reset.php をサーバーの
 taf-design.com/public_html/ku-fudo-chat/
に追加し、続いて同梱の index.php を同じ場所に上書きします。
index.phpはGitHubの最新メール配信版を基に、ログイン画面の案内1か所だけを変更しています。サーバーのみで独自編集した場合は、案内文の部分に <a href="password-reset.php">パスワードを忘れた方はこちら</a> を追加する方法もあります。
会員DB・config.phpは上書きしません。専用テーブルは自動追加します。旧ページ・管理サンプルは変更しません。

会員の操作：
1. ログイン画面の「パスワードを忘れた方はこちら」を押す。
   直接URL：https://taf-design.com/ku-fudo-chat/password-reset.php
2. 登録したメールアドレスを入力し「再設定メールを送る」を押す。
3. メールのリンクを30分以内に開く。
4. 新しいパスワード（8文字以上）を2回入力し「このパスワードに変更する」を押す。
5. 新しいパスワードでログインする。

複数回メールを申し込んだ場合は最後のリンクだけが有効です。リンクを開くだけではパスワードは変わりません。
再設定に成功すると、古いログインセッション・専用ログインリンク・再設定リンクを無効化します。
承認済みかつ利用中のメールアドレス付きアカウントが対象です。旧IDのみのアカウントや承認前の申し込みは対象外です。
登録の有無を第三者に知らせないため、未登録のアドレスにも画面上は同じ受付案内を表示します。
IPごと1時間10回、メールアドレスごと1時間3回に制限しています。
再設定リンクやパスワードを他の人に渡さないでください。

送信元の初期値：info@taf-design.com（既存approval_mail_fromがあればその値）。
変更が必要な場合のみ、非公開config.phpの配列内に以下を追加します。
'password_reset_mail_from' => 'info@taf-design.com',
'password_reset_mail_enabled' => true,
'chat_login_url' => 'https://taf-design.com/ku-fudo-chat/',

初回確認：ご自身の会員メールアドレスで1回試し、実際の受信・新パスワードでのログインを確認してください。
実メールの送信はサーバー設置後に確認が必要です。開発テストは模擬送信のみで、会員へメールを送っていません。
検証済み：CSRF、8文字以上の条件、確認用パスワードの一致、トークンのハッシュ保存、GETで消費しない、期限切れ、使い回し拒否、登録情報変更後の無効化、旧セッション失効、送信回数制限、停止会員の除外。
