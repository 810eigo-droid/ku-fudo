## エックスサーバーへの設置
設置先案: https://810eigo.online/ku-fudo-demo/
このURLは設置後に有効になります。自動設置は行っていません。

1. GitHubの「Code」→「Download ZIP」でダウンロードし、PCで展開します。
2. エックスサーバーのファイルマネージャーで、810eigo.online の public_html を開きます。
3. 同名のフォルダやWordPressページがないことを確認し、ku-fudo-demo フォルダを新規作成します。存在する場合は上書きせず、別名にしてください。
4. このリポジトリの ku-fudo-demo 内の index.html / style.css / app.js の3ファイルを、作成したフォルダへアップロードします。
5. https://810eigo.online/ku-fudo-demo/ を開きます。

配置:
- public_html/ku-fudo-demo/index.html
- public_html/ku-fudo-demo/style.css
- public_html/ku-fudo-demo/app.js

リポジトリ全体やREADMEは公開フォルダへアップロードする必要はありません。
既存WordPressの index.php やルートの .htaccess は変更・上書きしないでください。
本サンプルはNode.jsやデータベース不要です。

## 閲覧制限と注意
- 提案用フォルダにエックスサーバーのアクセス制限を設定し、先生に見せる前に未ログイン状態で制限を確認してください。
- 閲覧用パスワードはサイトの会員ログインとは別です。
- HTMLに noindex,nofollow を入れていますが、検索除外の指示はアクセス制限ではありません。
- このGitHubリポジトリは公開です。パスワード、会員情報、実際のZoom参加URL、有料教材などをコミットしないでください。
- 本番化する際は認証・会員権限・データ保存・バックアップ等を別途実装します。

## 確認方法
レッスンを開く→閉じる、完了ボタン→件数と進捗の更新、全6件完了、再読み込みでリセット、スマホ幅の表示を確認してください。
