# 会員マイページと管理者画面の操作確認

入口は index.html です。ログイン不要の仮データによる見本です。

## 確認する順番
1. 「最初のレッスンを開く」でチェックとメモを保存。マイページの進捗が変わります。
2. 会議の案内から申し込み、承認待ちの表示を確認。
3. 上部の「管理者側の見本」を開き、参加条件（有料なら入金も）の確認にチェックして承認。
4. 会員側へ戻ると承認済みの参加ボタンが表示されます。ボタンは実際のZoomには接続しません。
5. 管理者側でコースを案内すると、会員トップにその表示が反映されます。

仮の操作データは同じタブのsessionStorageに保存します。「登録情報」からリセットできます。別端末・別タブへの共有を保証するものではありません。仮の申込・メモはサーバーへ送信しません。メール送信、認証、入金処理は行いません。実際の個人情報を入力しないでください。

本番への接続前に確認する画面案です。参加資格を保護する本番のサーバー側の認可・承認機能は未実装です。JavaScriptによる見本上の表示切り替えを、本番のアクセス制御として使用しないでください。既存のPHPページやカリキュラムは変更していません。

V1には更新前コードを保存しています。実サーバー上の会員データ・設定のバックアップは含まれません。

## 検証状況
DOM操作テストでチェック・メモ保存、メモの管理画面非表示、申込・承認・取り消し、コース案内、各画面遷移を確認しました。ブラウザー実行環境を利用できず、画面の実レンダリングとスマホでの実表示確認は未完了です。
