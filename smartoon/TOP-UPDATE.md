# TOPに漫画入口を追加する更新

27歳と78歳の先生のイラストを並べ、カリキュラムの前に「漫画で知る 空不動先生の歩み」を追加。
第1話へ直接リンクします。

## サーバー更新
1. ku-fudo-top-smartoon-update.zip を解凍します。
2. 中の ku-fudo-demo と ku-fudo-smartoon の2フォルダを、対象ドメインの public_html 直下にアップロードします。
3. ku-fudo-demo/index.html は上書きしてください。他の既存ファイルは削除しません。
4. TOPを再読み込みし、「第1話を読む」を押して表示を確認します。

TOP例：https://taf-design.com/ku-fudo-demo/
漫画例：https://taf-design.com/ku-fudo-smartoon/episode-01/

ZIPにはTOP更新用4ファイルと漫画本編9ファイルのみを含みます。漫画をまだアップしていなくても、このZIPで入口と本編がそろいます。
既存TOPのスタイル・ナビゲーション・スクリプト・画像はサーバーに設置済みのものを使用します。
自動でサーバーへの反映は行いません。アップロード後に反映されます。
