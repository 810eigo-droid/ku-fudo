# 第9話 山に籠もらぬ「徹底した現実主義」

全7コマ。第1話の人物を固定参照、添付された本人のスーツ写真を服装の基準に制作。身長180cm、細身、同じ髪型・眼鏡・顔立ち・画風を維持。

衣装：濃いチャコールのシングル2ボタンスーツ、適度な幅のノッチドラペル、白シャツ、紫の小紋ネクタイ、黒い革靴。自然な肩と適度に絞った身幅。全コマでスーツを着用。

画像生成は組み込みimage_gen。共通・各コマのプロンプトは image-prompts.json、漫画用台詞は script.md。

会社名・業績数値・私生活の情報は創作しない。背景人物は演出。第8話末尾から第9話へ、全話一覧からも第9話へ移動可能。第10話は最終話。

顔向き修正：第1コマは画面左向き、第4コマは正面向き。表示は panel-01-v2.webp と panel-04-v2.webp を使用。背景・体のポーズ・衣装は維持。

人物描写の修正：第5コマを食卓から一人で仕事に向き合う場面へ差し替え。家庭人としての描写と「社員を守る」という人物評価を外し、経営・真理探究を軸に語りを整理。新たな私生活エピソードは追加しない。現行画像は panel-05-work.webp。
