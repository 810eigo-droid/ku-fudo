# 第6話 霊現象の限界〜「神のロボット」からの脱却

## 原案
ユーザー添付「スマートゥーンのコマ割りやセリフ、筋書きなど」第6話、全7コマ構成を使用。相談への助言、違和感、思考停止への気づき、水面と深さの比喩、筆を置く、自分の足で踏み出す、日常へ向かうという順序を維持。
霊能力で多くの人を救ったという実証済みの事実にはせず、相談と助言、感謝された場面を描く。体験や解釈は原案の語りとして扱う。水面の概念図は科学的説明ではなく主人公の思索を伝える比喩。操り人形は背景の影として描き、身体を縛る実際の糸は使わない。
相談者の具体的な人物像と台詞、一部ナレーションは漫画上の補作。本文表記は空不動先生、年齢の数字は表示しない。

## 衣装と画像
第1・6・7コマはグレーブラウンのジャケット＋白バンドカラーシャツ＋黒系細身パンツ。第2・3・5コマは白シャツのみ。長身180cm・細身・眼鏡の造形を継続し、全身コマでは靴まで収める。
第4コマは水面と水中の比喩的な風景。組み込み画像生成を使用し、プロンプトは image-prompts.json に保存。
