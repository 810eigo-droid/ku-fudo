# 空不動先生 スマートゥーンプロジェクト

更新日：2026-09-13

空不動先生の人生を27歳から描く、縦読みスマートゥーンの人物・画風設定です。
今後の制作では本ファイルを読み、共通設定を維持してください。

## 使用方法

下の共通プロンプトをコピーし、末尾の「今回の指定」を書き換えて使用します。
該当年代の作成済みイラストも参照画像として添付すると、顔と画風をそろえやすくなります。
27歳・40歳・60歳の姿は、本人写真と面影をもとにした想像上の年代別表現です。

**ユーザー確定事項：身長180cm、実物は細身。全年代ですらっとした体型を維持します。**
78歳は、細身に修正した最終イラストを基準にします。

## 画風の言語化

「人物の特徴を残した、すっきりした輪郭線と控えめな陰影の大人向けセミフラットイラスト」。
一般的なアニメより顔や体の比率が現実的で、漫画として読み取りやすく整理された表現です。

## 共通プロンプト

添付のキャラクター画像を基準に、空不動先生が登場する縦読みスマートゥーンの一場面を描いてください。以下の画風・人物設定を、すべての年代とコマで統一してください。

【共通の画風】
人物の特徴を残した、大人向けのセミフラットな2Dイラスト。
すっきりした黒〜濃いグレーの輪郭線で、顔・服・手の形を明確に描く。線の太さはおおむね均一にし、外側の輪郭をわずかに強める。
着色は落ち着いた色のベタ塗りを基本とし、立体感に必要な薄い影だけを加える。肌や衣服の写実的な質感、強いグラデーション、光沢は抑える。
顔は適度に簡略化しながら、本人の目元・鼻・口・輪郭を残す。表情は自然で穏やかにする。
服の縫い目やしわは必要なものに絞り、スマートフォンでも人物の表情と動作が読み取りやすい画面にする。

【全年代で変えない人物設定】
日本人男性、空不動先生。同一人物の人生を年代別に描く。
身長180cm。胴回りと手足が細く、すらっとした健康的な体型。自然な7.5〜8頭身を目安とし、肩幅や胸板を大きくしすぎない。
顔は添付画像を基準とした、やや縦長で頬に柔らかさのある輪郭。細い金属フレームの横長の眼鏡、穏やかな目元、自然な眉、落ち着いた口元が特徴。
髪は短めで、分け目から横へ流す。年代が変わっても、目・鼻・口の配置、眼鏡の特徴、基本的な骨格は維持する。
年齢差は、髪色・生え際・肌の張り・頬や顎の変化・目元や口元のしわで表現する。高齢になることを、体の横幅が増えることで表現しない。

【年代別の外見と標準衣装】
■27歳
黒髪で白髪はない。肌に張りがあり、目元・口元に加齢のしわはない。先生の面影を残した自然な青年の顔。
青い無地のクルーネックセーター、またはトレーナー。濃いグレーのパンツと白いスニーカー。

■40歳
黒髪を基本とし、青年期より落ち着いた顔立ち。しわはごく控えめで、老けさせすぎない。
細身のダークチャコールのスーツ、白い開襟シャツ、黒い革靴。ネクタイは着けない。

■60歳
こめかみを中心に白髪が混じる。目元と口元に控えめなしわがあり、自然な成熟を感じる顔立ち。
青地に細い白の縦ストライプが入った長袖ボタンダウンシャツ。襟先の小さなボタンも描く。濃いグレーのパンツ、黒いベルトと革靴。

■78歳
添付された78歳の本人写真と、細身に修正したイラストを優先する。
黒髪に白髪がしっかり混じり、髪を横へ流す。目元・口元・額には自然なしわがあり、頬と顎にも年齢相応の変化がある。穏やかで生き生きした表情。
黒いジャケットに、クリーム・グレー・紺・くすんだ赤の大きなチェック柄のボタンダウンシャツ。濃いグレーのパンツと黒い革靴。
身長180cmの細身の体格を維持し、過度に猫背や衰弱した姿にしない。

【場面の描き方】
指定された場面に合わせて、構図・表情・ポーズ・背景を変える。
背景にも人物と同じ線と塗りを使い、状況が伝わる範囲に描写を整理する。
複数のコマで、顔立ち・髪型・体格・衣装・色を統一する。
文字や吹き出しは、別途指定がある場合だけ入れる。

【避ける表現】
太い胴体、がっしりした肩、短い脚、極端な小顔、筋肉質な体型、ちびキャラ、大きすぎるアニメの目、過度な美青年化、年齢以上の老け顔、深すぎるしわ、写真風の肌、3D表現、濃すぎる陰影。
年代によって別人の顔に変えない。
