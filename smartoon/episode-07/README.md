# 第7話 袋小路からの脱出〜「判断放棄」という究極の決断

原案：添付「スマートゥーンのコマ割りやセリフ、筋書きなど」第7話。知識の壁、真理もどき、判断放棄、不安、執着の手放し、静寂、壁の先という7コマの順序を維持。一部の台詞と語りを補作。目隠し運転の恐怖は霧の道の比喩へ変更。判断放棄は主人公の内面の転機として描き、危険な運転や目隠し歩行は描かない。箱や壁は象徴的な演出。体験を実証された事実として断定しない。

## 固定画風
ユーザー承認：背景は豊かに、人物は第1話に近づける。人物は episode-01/assets/panel-01.webp を毎回の基準にする。輪郭・眼鏡・小さい目・大きな髪の束を統一し、肌は少ない陰影。精密なアニメ顔、尖った顎、髪の細線、光沢は避ける。背景は奥行き、生活感、人々、家具、植物、照明を豊かに描く。直前の話だけを人物基準にしない。
第1コマは承認済み修正版。第2〜7コマも同じ人物基準と修正版を参照して組み込み画像生成で制作。プロンプトはimage-prompts.json。身長180cm・細身、全身では靴まで。
