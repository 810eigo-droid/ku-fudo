# 統一行 Webマンガ

全10コマの静的縦読みマンガ。HTML内のセリフを編集可能。

公開URL: https://ku-fudo-tougyou.ricky-o.chatgpt.site/

GitHub保存先: 810eigo-droid/ku-fudo の smartoon/tougyou/

## エックスサーバーへの設置

public 内の index.html、style.css、reader.js、favicon.svg、robots.txt と assets フォルダを、ku-fudo-smartoon/tougyou/ に配置すると利用できます。サイト内の外部リンクは絶対URLです。移設を正式な公開先にする場合は canonical と og:url、og:image を実際のURLへ更新してください。

## 画像

image_gen で10コマを生成。読者役と部屋の整合のため3・7・8・9コマを再生成。WebPに変換して軽量化しています。

セリフは提供シナリオを表示用に分割。未解決の出典番号は表示しません。効果に関する語りは教え・体験の表現として巻末で補足しています。
