「心の不安すらコントロールできない」は原案のセリフ。その他のセリフやつなぎの語りは補作。
ユーザー希望により看護師、他の患者、見舞い客を演出として追加。実在する特定人物としては扱わない。
病名、治療方針、病気の治癒は描写・断定していない。
光や紙の場面は思考の変化の比喩。資料や治療を捨てる描写ではない。
