# 第3・4話と話選択メニューの更新

ZIPは第1〜4話の画像・HTML・CSS・JavaScriptを含む完全セットです。

1. ZIPを解凍し、中の ku-fudo-smartoon を開きます。
2. サーバーの public_html/ku-fudo-smartoon/ に中身を上書きします。同名フォルダを二重に作らないでください。
3. 第3話：public_html/ku-fudo-smartoon/episode-03/index.html、第4話：episode-04/index.html が存在することを確認します。
4. story-menu.css と story-menu.js は ku-fudo-smartoon の直下に置きます。
5. 更新後、ブラウザーで Ctrl+F5 を押し、新しいメニューから第3話・第4話を開きます。

公開サーバーの状態を取得できなかったため、以前の第3話が反映されない原因は特定できていません。今回のZIPでは画像も含めて同梱し、リンクに更新番号を付けています。
