# 第4話 突然の啓示と霊修行の始まり

## 原案と編集
Google Docs「スマートゥーンのコマ割りやセリフ、筋書きなど」第4話のシナリオと7コマ構成を使用。取得した現行原稿を参照。主なセリフを維持し、スマホでの可読性のため一部短縮・改行。表記を空不動先生へ統一。

年齢を入れたくないというユーザー指定に合わせ、タイトル・カレンダー・ナレーションには年齢の数字を表示しない。青年期の造形は維持。

第3コマは原案の「街へ出て用具を手配」を文具店の場面に具体化。店主と客は補作。第4コマ「無礙自在」は正確な文字をHTMLで表示。第6・7コマは選民意識・教祖化を拒絶する原案の趣旨を維持。霊的体験や能力は原案に記された本人の体験の描写であり、独立に実証したという表現はしない。

## 衣装
室内の第1・2・4・5コマ：白バンドカラーシャツ＋黒パンツ、ジャケットなし。
外出・対話の第3・6・7コマ：グレーブラウンのジャケット＋白シャツ＋黒パンツ。全身では黒革靴まで描写。
顔と体格は従来どおり。参照ファッション写真の顔は使用しない。

## 制作
組み込み画像生成を使用。画像生成プロンプトは image-prompts.json。
