# 第1話：サーバーアップロード版

第1話「科学者を志した青年と『99%の無神論』」全7コマ。

## アップロード方法
1. ダウンロードした ku-fudo-smartoon-episode-01.zip をPCで解凍します。
2. 中の ku-fudo-smartoon フォルダをドメインの public_html 直下へアップロードします。
3. 公開URLは https://あなたのドメイン/ku-fudo-smartoon/episode-01/ です。
   taf-design.comへ置く場合の例：https://taf-design.com/ku-fudo-smartoon/episode-01/
4. index.html、style.css、reader.js、assets内の6画像を一緒にアップしてください。

GitHubから取り出す場合はこのフォルダ（smartoon/episode-01）の index.html、style.css、reader.js、assets を同じ階層のまま配置してください。

## 編集
- セリフ・ナレーション：index.html
- デザインと文字サイズ：style.css
- イラスト：assets/
- 補作と原案の区別：episode-01-script.md

通常の静的ページなので、PHP・データベース・WordPress・APIキー・ビルドは不要です。
Sitesの本人限定アクセスは含まれません。通常の公開フォルダに置くと誰でも閲覧できます。
