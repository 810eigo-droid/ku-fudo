# 第5話 信頼の揺らぎと「化け猫」の声

## 原案と安全な脚色
ユーザー添付「スマートゥーンのコマ割りやセリフ、筋書きなど」第5話を参照。原案の危機、助かった後の体験、化け猫の声による揺さぶりを軸に全7コマへ再構成。
危険な行為の具体的な方法や道具・身体への作用は描かない。原案の危険行為を精神的な成長や加護の証明として称賛する結末は採用しない。「体験をどう受け止めるか」という葛藤を残し、第6話の霊現象の限界へ接続。原案の結末からの変更はユーザーへ説明済み。
声や猫の影は主観的体験の演出。知人の訪問・水を持つ場面・会話は漫画上の補作であり史実とは断定しない。診断や治療の説明は追加しない。

## 絵と服装

## ページ
第1〜5話のハンバーガーメニューから第5話を選択。第4話末尾に第5話へ進むボタン。全話一覧の第5話を公開枠へ移動。第6〜10話は準備中。
